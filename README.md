# AutoNusa - Marketplace Mobil

Prototipe website marketplace jual-beli mobil.

## Fitur
- Pencarian dan filter mobil
- Form untuk menjual mobil
- Simulasi kredit mobil
- Artikel & tips untuk pembeli

## Teknologi
HTML, CSS, dan JavaScript (tanpa framework).

## Cara menjalankan
Clone repo ini lalu buka `index.html` di browser.
